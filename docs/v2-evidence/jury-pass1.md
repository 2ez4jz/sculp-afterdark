# Independent blind jury review — pass 1

**The idea I can read:** SCULP presents personal beauty as a set of deliberate visual choices, inviting visitors to read three looks, identify an artist and carry a direction into an enquiry.

This is an evidence-only estimate under `quality-bar.md`, not an award result. I read the rubric in full, inspected all 76 current first-screen views across 19 routes at 1440, 768, 390 and 375 pixels, all ten current full-page screenshots, the selected mobile study state, and all supplied earlier Home hover, transition, focus, reduced-motion and scroll frames. Current matrix evidence supersedes the earlier logo accessible-name violation. No source, design notes, earlier scorecards, baseline or calibration was read.

## Ranked fixes

1. **Make the existing “closer reading” idea visible in the case-study composition.** In `1440-full-studies-modern-chinese-.png` and `390-full-studies-modern-chinese-.png`, the second image repeats the hero almost unchanged. Replace that repeat with a deliberate crop of the collar/face/hair relationship, or show the existing detail-selection treatment alongside that crop. Tie each of the three text observations to a visible region. Carry the same discipline into the other two study pages. This would improve Creativity, Design and Content using the idea already present, without adding a new concept.

2. **Put the saved studio brief where phone users can use it.** `390-full-book-.png` places the brief after the fields and “What happens next.” Move a compact saved-look/detail summary above “Your plans” on phone, with a small thumbnail, exact selected detail, clear Remove/Edit action and the service/artist preference. Keep the longer explanation lower down if needed. The interaction checks prove the data survives; the on-screen hierarchy should make that benefit immediately apparent. Primary gain: Usability; secondary gain: coherence of the signature interaction.

3. **Recover image presence in the first phone screen.** In `390-home.png`, shorten the vertical gap below the blue wordmark and tighten the copy/CTA stack enough to introduce a meaningful portion of the hero portrait before the screen ends. In `390-team.png` and `375-team.png`, reduce the large blank interval between the introduction and first portrait; aim to show a face and artist identity in that initial view. Preserve the current comfortable body text and touch-target sizes. This improves the existing visual direction, rather than inventing a new one.

4. **Give page changes and the remaining weak link a visible relationship.** The Home → Portfolio `d-90-transition-a/b/c.png` samples are already at the destination; no continuous bridge is visible. Provide a short, nonblocking connection using the current portrait/wordmark/blue visual language and capture enough intermediate frames to demonstrate it. In `h-07-rest.png` → `h-07-hover.png`, replace the underline-only attribution response with the same small arrow movement used by neighboring text links. Keep all such treatments disabled or immediate under reduced motion. Primary gain: Animations/Transitions, with a smaller Design gain.

5. **Replace broad artist claims with concrete selection help.** `390-artist-emily.png` says “A thoughtful, detail-oriented approach to personal beauty”; Elaine and Michelle use similarly broad claims. Add one or two verified specifics per artist—signature technique, strongest occasion, training, working approach or representative look—and place that information in a consistent small comparison block before the long gallery. The three existing studies already show how useful concrete visual language can be. Do not invent client outcomes or credentials. Primary gain: Content and artist-choice usability.

6. **Resolve the performance uncertainty with a clean, isolated measurement, then fix the demonstrated cause.** Re-run the throttled phone Home scroll without concurrent screenshot work. Record a trace for the 150ms spike if it repeats; only then reduce the responsible animation, image decode or scroll work. Measure initial transfer and LCP on Miranda's gallery separately before treating the 5.3MB inventory warning as an initial-load failure. Current evidence already supports a fast Home paint, so avoid adding a loader or delaying the hero.

7. **Complete the review evidence for static delivery and metadata.** Expand `current-audit.txt` to show all 19 route responses and the individual checks for real 404 status, headings, canonical, sitemap/robots, OG/Twitter, favicon and OG-image fetch. This is an evidence gap rather than a proven user-visible defect. It would make the present Semantics/SEO and Markup scores easier to validate and could earn 8s if every required row passes.

## Evidence limits

The 17 interaction checks used mocked POST requests and created no emails or customer records; they support the client workflow and failure handling, not successful live delivery. Stills support composition and state differences, not the perceived fluidity of motion. The corrected matrix is authoritative for current accessibility and layout. Performance is a local throttled lab sample, partly gathered under concurrent work, and is not field CWV. The audit's raw gallery asset inventory is not initial transfer.
