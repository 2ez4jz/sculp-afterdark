# SCULP Studio — independent evidence-only jury estimate

This is an independent simulated estimate against the supplied Awwwards-style rubric, not an official Awwwards review. Every category began at 6; the increases below are earned from the permitted screenshots and measurements. No source code, design notes, previous scorecards or historical collections were consulted.

**The idea read from the screens:** SCULP helps a visitor discover a personal beauty direction by looking closely at real artists’ work, saving the particular detail that speaks to them and bringing that reference into a studio enquiry.

## Ranked improvements

1. **Resolve the variable main-thread/scroll behaviour.** Start with `release-performance-repeat/report.json` Occasions cold/warm (50.86/50.71 fps), Modern Chinese warm (54.44 fps) and the 100–150 ms intervals; retain the first About warm outlier too. Profile the actual work during those windows before assigning a cause, then reduce or defer the blocking layout, image or script work the profile identifies. Validate with both existing methods and a physical mid-range phone. This has the clearest path to raising Usability, Animations and WPO together.
2. **Tighten the long mobile rhythm.** `matrix/390-full-home.png` is 9,018 px high and `390-full-bridal.png` is 12,114 px high. The service content is useful, but generous section gaps and repeated invitation blocks make the path feel more uniform than the desktop compositions. Reduce the mobile spacing around the later studio/testimonial/enquiry blocks and make repeated pricing comparisons more compact while preserving every service, condition and direct price jump.
3. **Give the studies a documented brief-to-result layer.** `matrix/390-full-studies-fresh-bridal.png` and `390-full-studies-modern-chinese.png` explain visual balance well; they contain less evidence of the real occasion, the client’s constraints and the confirmed outcome. Add those specifics from verified studio material, plus relevant collaborator credits, beside the existing detail reading. Preserve the distinction between visible observations and the artist’s documented decisions. This would add content depth and make the studio-specific idea harder to transplant.
4. **Make the smallest navigation responses more expressive within the existing language.** The actual pairs for `release-ui/nav-*`, `artist-index-*`, `about-next-*` and `team-next-*` show real but slight 2–3px movement. Extend the existing crop/selection or rule treatment to make those responses as deliberate as the image/detail interactions, while keeping their speed and reduced-motion clarity.
